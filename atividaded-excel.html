TRILHA 1 — EXCEL

Atividade Final

Agora é hora de colocar em prática os conhecimentos trabalhados nas aulas da Trilha de Excel.

Objetivo da atividade

Aplicar os conhecimentos aprendidos durante as três aulas para realizar uma análise de dados utilizando o Excel.

A atividade reúne conceitos de organização e limpeza de dados, funções, tabelas dinâmicas e gráficos.

O que você deverá fazer?

Utilize o arquivo disponibilizado abaixo e realize as atividades propostas seguindo as instruções presentes na planilha.

01 — Limpeza dos dados Organize e prepare os dados para a análise.
02 — Criar métricas Utilize funções do Excel para realizar os cálculos solicitados.
03 — Tabela dinâmica Crie tabelas dinâmicas para analisar os dados.
04 — Gráficos Crie gráficos adequados para representar os resultados.
05 — Interpretação Analise os resultados encontrados.
06 — Conclusões Apresente as principais conclusões obtidas na análise.

Conteúdos utilizados

Para realizar a atividade, você poderá utilizar os conhecimentos desenvolvidos ao longo das aulas:

  • Organização de planilhas
  • Filtros e ordenação
  • Formatação
  • Funções do Excel
  • Funções condicionais
  • Funções de texto
  • Funções de data
  • Tabelas dinâmicas
  • Segmentação e filtros
  • Gráficos
  • Interpretação de dados
